# OpenClaw 专家龙虾获取指南

## 核心流程（3步）

```
搜索 → 安装 → 验证
```

| 步骤 | 命令 | 说明 |
|------|------|------|
| 1. 搜索 | `openclaw skills search <关键词>` | 查找想要的龙虾 |
| 2. 安装 | `openclaw skills install <slug>` | 一键下载并自动配置 |
| 3. 验证 | `openclaw skills list --eligible` | 确认安装成功 |
