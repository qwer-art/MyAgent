## 二、研究概览（核心五问）

### 2.1 研究目标

**核心问题**：扩散模型是否需要使用卷积神经网络（CNN）作为backbone？

**研究动机**：
- 现有扩散模型（如DDPM、Stable Diffusion）都依赖U-Net作为骨干网络
- U-Net本质上基于CNN架构，限制了模型的扩展性
- Transformer在NLP和视觉领域展现出优越的scaling properties
- 需要探索：能否用纯Transformer替代U-Net？

**研究目标**：
1. 提出DiT（Diffusion Transformer）架构，用Transformer替代U-Net
2. 系统研究扩散模型的scaling properties
3. 证明Transformer在图像生成任务中的有效性
4. 探索模型规模与性能的关系

**应用场景**：高分辨率图像生成、类别条件生成、文本到图像生成

### 2.3 数据格式

#### 输入数据格式

**图像 → Latent表示**：
- **原始图像**: 256×256×3 (RGB图像)
- **VAE编码后**: 32×32×4 (latent表示)
  - 空间压缩: 8× (256/32 = 8)
  - 通道数: 4个通道 (z ∈ R^{4×32×32})

#### Patch化处理

```
Latent: 4 × 32 × 32
    ↓
Patchify (patch size p = 2 or 4)
    ↓
For p=2: 4 × (16×16) patches → 每个patch: 4×2×2 = 16维
For p=4: 4 × (8×8) patches → 每个patch: 4×4×4 = 64维
    ↓
展平为token序列: N = H×W/p² 个tokens
```

#### 条件输入格式

**1. 时间步条件 (timestep conditioning)**：
```
t → Sinusoidal embedding → LayerNorm → Linear → 添加到每个token
```

**2. 类别条件 (class conditioning)**：
```
class label → Embedding → LayerNorm → adaLN (adaptive layer norm)
```

**adaLN机制**：
```python
# 伪代码
scale, shift = adaLN(condition)
y = scale * LayerNorm(x) + shift
```

#### 输出格式

- **预测目标**: 噪声 ε (或速度 v)
- **输出维度**: 与输入latent相同 (32×32×4)
- **训练目标**: 简化的去噪目标 (如DDPM/DDIM formulation)

#### 扩散模型发展脉络

```
DDPM (2020) → DDIM (2021) → LDM/Stable Diffusion (2022) → DiT (2022)
     ↑              ↑                    ↑                        ↑
   U-Net          U-Net               VAE+U-Net              Transformer!
```

- 为什么所有扩散模型都用U-Net？
- 传统思维：CNN适合图像，Transformer适合序列
- 但Vision Transformer (ViT, 2021) 已经证明CNN不是必须的

#### Transformer的优势

1. **Scaling properties优越**: GPT系列证明
2. **架构简洁**: 标准的Transformer block
3. **易于扩展**: 自注意力机制天然适合全局建模
4. **研究活跃**: 大量优化方案 (FlashAttention, etc.)

### 3.2 核心研究问题

**Main Research Question**:
> Can we replace the U-Net backbone in diffusion models with a standard Transformer architecture like Vision Transformer (ViT), while achieving competitive or better performance?

**Sub-questions**:
1. 如何将图像适配到Transformer输入？
2. 如何在Transformer中注入时间步和类别条件？
3. DiT的scaling law是什么？参数增加如何影响性能？
4. 如何设计高效的Transformer-based扩散模型？

## 四、第二遍：精细阅读

### 4.1 建模假设与数学推导

#### 扩散模型基础

**前向过程 (Forward Process)**:
```
q(x_t | x_{t-1}) = N(x_t; √(1-β_t)x_{t-1}, β_tI)
q(x_t | x_0) = N(x_t; ᾱ_t x_0, (1-ᾱ_t)I)
```

**反向过程 (Reverse Process)**:
```
p_θ(x_{t-1} | x_t) = N(x_{t-1}; μ_θ(x_t, t), Σ_θ(x_t, t))
```

**训练目标**:
```
L = E_{x_0, ε, t} [||ε - ε_θ(x_t, t)||²]
```
其中 x_t = ᾱ_t x_0 + √(1-ᾱ_t)ε

#### DiT的建模

**关键设计1: Latent Diffusion**

使用预训练VAE将图像压缩到潜空间：
```
E_φ: R^{H×W×3} → R^{h×w×c}  (h=H/8, w=W/8, c=4)
```

在潜空间做扩散，减少计算量。

**关键设计2: Transformer建模**

将latent视为一系列patches：
```
z ∈ R^{c×h×w} → {z_1, z_2, ..., z_N}  (N = h×w/p²)
```

**前向过程**:
```
z_0 = E_φ(x)  # VAE encoder
z_t = ᾱ_t z_0 + √(1-ᾱ_t)ε  # add noise
```

**DiT网络预测**:
```
ε_θ(z_t, t, c) = Transformer(z_t, t, c)
```

其中:
- z_t: noisy latent (patchified)
- t: timestep (scalar)
- c: class label (optional)

#### adaLN数学推导

**标准LayerNorm**:
```
LN(x) = γ · (x - μ)/σ + β
```

**自适应LayerNorm (adaLN)**:
```
γ, β = MLP_condition(t, c)
adaLN(x) = γ(t, c) · LN(x) + β(t, c)
```

**DiT Block中的adaLN**:

```python
# 伪代码
def DiT_block(x, t, y=None):
    # 1. 自注意力
    norm_x = adaLN(x, t, y)
    attn_out = Attention(norm_x)
    x = x + attn_out

    # 2. 前馈网络
    norm_x = adaLN(x, t, y)
    mlp_out = MLP(norm_x)
    x = x + gate(t, y) * mlp_out  # zero-init

    return x
```

**注意**: gate机制用于初始化，确保训练初期block接近恒等映射。

#### 条件注入机制

**时间步嵌入**:
```
t → SinusoidalPosEmb(t) → MLP(t_emb)
t_emb ∈ R^{d_model}
```

**类别嵌入**:
```
y → Embedding(y) → MLP(y_emb)
y_emb ∈ R^{d_model}
```

**组合条件**:
```
cond = t_emb + y_emb  # 或 concat
γ, δ = MLP(cond)  # 生成scale和shift
```

### 4.2 算法设计与架构

#### DiT完整架构

```
输入: z_t ∈ R^{c×h×w}, t, y
    ↓
Patch Embedding: z_t → {z_1, ..., z_N}  (N = hw/p²)
    ↓
添加位置编码: z_i = z_i + pos_emb_i
    ↓
┌──────────────────────────────────┐
│   DiT Block × depth              │
│   ┌─────────────────────────┐    │
│   │ adaLN → Self-Attn → Add  │    │
│   │ adaLN → MLP → Gate → Add │    │
│   └─────────────────────────┘    │
└──────────────────────────────────┘
    ↓
adaLN (final)
    ↓
Unpatchify: {z_1, ..., z_N} → z_0_pred ∈ R^{c×h×w}
    ↓
输出: ε_pred (预测噪声)
```

#### DiT Block详解

**1. Self-Attention子模块**:
```python
class Attention(nn.Module):
    def forward(self, x):
        B, N, C = x.shape
        qkv = self.qkv(x).reshape(B, N, 3, self.heads, C//self.heads)
        q, k, v = qkv.unbind(2)
        attn = (q @ k.transpose(-2, -1)) * self.scale
        attn = attn.softmax(dim=-1)
        x = (attn @ v).transpose(1, 2).reshape(B, N, C)
        return x
```

**2. MLP子模块**:
```python
class MLP(nn.Module):
    def forward(self, x):
        x = self.fc1(x)
        x = GELU(x)
        x = self.fc2(x)
        return x
```

**3. adaLN参数生成**:
```python
def adaLN_modulation(cls, condition):
    # condition: (B, d_cond)
    shift, scale, gate = self.conditioner(condition).chunk(3, dim=1)
    return shift, scale, gate
```

#### 模型变体

| 模型 | Depth | Hidden Size | Heads | Patch Size | Params |
|------|-------|-------------|-------|------------|--------|
| DiT-S | 12 | 384 | 6 | 4 | 33M |
| DiT-B | 12 | 768 | 12 | 4 | 130M |
| DiT-L | 24 | 1024 | 16 | 4 | 456M |
| DiT-XL | 28 | 1152 | 16 | 4 | 675M |

**设计规律**:
- Depth: 随模型增大而增加
- Width (hidden size): 主要参数量控制
- Heads: hidden_size / 64
- 固定patch size=4 (最优)

#### 计算复杂度分析

**Self-Attention复杂度**:
```
O(N²d)  # N = number of patches, d = hidden size
```

对于DiT:
- N = (32/4)² = 64 patches (256×256输入)
- N = (64/4)² = 256 patches (512×512输入)

**MLP复杂度**:
```
O(Nd²)
```

**总体复杂度**:
```
Gflops ≈ O(N × depth × hidden_size²)
```

### 4.3 训练策略与损失函数

#### 损失函数

**简化损失 (DDPM-style)**:
```
L_simple = E_{z_0, ε, t, y} [||ε - ε_θ(z_t, t, y)||²]
```

其中:
- z_0 ~ E_φ(x)  # VAE encoder输出
- ε ~ N(0, I)   # 标准高斯噪声
- t ~ Uniform(1, T)  # 均匀采样时间步
- y ~ class label (可选)

**预测目标**:
- **ε-prediction**: 预测噪声
- **v-prediction** (可选): 预测速度 v = α_t z_0 - σ_t ε

#### 训练超参数

| 参数 | 值 | 说明 |
|------|-----|------|
| Batch size | 256 | 256×256训练 |
| Learning rate | 1e-4 | AdamW optimizer |
| Weight decay | 0 | 不使用权重衰减 |
| Beta schedule | Linear | β_1=0.0001, β_T=0.02 |
| Timesteps | 1000 | 扩散步数 |
| Warmup steps | 1000 | 学习率线性warmup |
| EMA | decay=0.9999 | 指数移动平均 |

#### 训练技巧

**1. Classifier-free guidance训练**:
```python
# 随机丢弃条件信息
y = None if random() < 0.1 else y  # 10% unconditional
```

**2. Zero-initialized输出层**:
```python
# 最后的线性层初始化为0
self.final_layer.weight.data.zero_()
self.final_layer.bias.data.zero_()
```

**3. EMA**:
```python
ema_model = decay * ema_model + (1 - decay) * model
```

#### 采样策略

**DDPM采样** (1000 steps):
```
for t = T, ..., 1:
    ε_t = ε_θ(z_t, t, y)
    z_{t-1} = 1/√ᾱ_{t-1} (z_t - β_t/√(1-ᾱ_t) ε_t) + σ_t z
```

**DDIM采样** (≤100 steps):
```
z_{t-1} = √ᾱ_{t-1} (z_t - √(1-ᾱ_t) ε_t)/√ᾱ_t + √(1-ᾱ_{t-1}) ε_{t-1}
```

**CFG采样**:
```
ε_final = ε_uncond + w * (ε_cond - ε_uncond)
```

其中w=4.0 (guidance scale)

### 4.4 复杂度分析

#### 计算复杂度对比

**DiT vs U-Net (LDM)**:

| 模型 | Gflops | Params | FID | Efficiency (FID/Gflops) |
|------|--------|--------|-----|------------------------|
| LDM-4 | 41.9 | 115M | 10.9 | 0.260 |
| DiT-B | 28.7 | 130M | 12.1 | 0.421 |
| LDM-8 | 163.8 | 415M | 4.6 | 0.028 |
| DiT-XL | 119 | 675M | 9.6 | 0.080 |

**结论**: DiT在相同参数量下更高效

#### 扩展性分析

**Scaling Law实验**:

```
log(FID) = a - b · log(compute)
```

观察:
- FID随计算量对数线性下降
- DiT的扩展性优于U-Net
- 尚未饱和（更大模型可继续提升）

#### 内存复杂度

**Attention内存**:
```
O(N²)  # attention matrix
```

对于256×256输入，N=64，内存可忽略
对于512×512输入，N=256，需要优化

**解决方案**:
- 使用FlashAttention (O(N) memory)
- 分层attention (局部+全局)

## 五、第三遍：批判性思考

### 5.1 优点分析

| 维度 | 优点 | 说明 |
|------|------|------|
| **架构简洁** | 无自定义架构 | 直接使用标准Transformer/ViT |
| **扩展性强** | 参数量33M→675M | FID持续下降，未饱和 |
| **计算高效** | 相同FID下Gflops更少 | 比U-Net节省约30%计算 |
| **通用性好** | 无条件/类别条件都行 | adaLN灵活注入条件 |
| **易于实现** | 代码清晰 | PyTorch原生支持 |
| **研究价值高** | 启发后续工作 | Stable Diffusion 3采用DiT |
| **理论清晰** | 无特殊技巧 | 标准扩散+Transformer |

### 5.2 局限性分析

| 局限 | 说明 | 严重程度 |
|------|------|----------|
| **高分辨率计算量大** | 512×512需要256个patches | 中等 |
| **训练不稳定** | 大模型训练需要careful tuning | 中等 |
| **采样速度慢** | 仍需1000步DDPM采样 | 低（通用问题） |
| **无文本条件** | 仅支持类别条件 | 中等（后续工作解决） |
| **VAS依赖** | 依赖预训练VAE | 低（LDM共同局限） |
| **消融不充分** | 部分设计choice缺少解释 | 低 |

### 5.3 改进建议

#### 对论文的改进

1. **更多架构消融**:
   - 不同attention机制 (flash, linformer)
   - 不同position encoding (learned, rotary)

2. **更系统scaling study**:
   - 训练计算量 vs FID (不只是参数量)
   - 数据量scaling (1M → 10M images)

3. **高分辨率实验**:
   - 1024×1024生成
   - 分层生成策略

4. **文本条件实验**:
   - 结合CLIP
   - 文本到图像生成

#### 对工程实践的改进

1. **训练加速**:
   - 混合精度训练 (FP16/BF16)
   - Gradient checkpointing
   - 分布式训练优化

2. **采样加速**:
   - DDIM/V sampling
   - One-step distillation
   - Progressive distillation

3. **内存优化**:
   - FlashAttention
   - Sequential attention
   - Cache-friendly implementation
