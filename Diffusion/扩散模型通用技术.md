## 1. Classifier-Free Guidance (CFG)

### 核心概念

**定义**：Classifier-Free Guidance 是一种无需额外分类器的条件生成增强技术，通过调节无条件预测和条件预测的权重来提升生成质量。

**一句话总结**：
> **同时训练条件模型和无条件模型，采样时按比例混合两者的预测，提升条件生成的质量。**

**直观理解**：
```
条件预测："生成一只猫"（按要求生成）
无条件预测："生成任何东西"（自由生成）

CFG 的想法：
    最终 = 无条件预测 + guidance_scale × (条件预测 - 无条件预测)
         ↑                      ↑
       保持多样性            强调条件符合度
```

---

### 为什么需要 Guidance？

#### 问题：质量 vs 多样性的权衡

```python
# 条件生成的困境

问题1：生成质量不够高
    - 文本："一只在草地上的猫"
    - 生成：像猫，但模糊/细节不足
    - 原因：模型"妥协"了，为了满足各种可能的猫

问题2：条件符合度不够
    - 文本："一只黑色猫"
    - 生成：是猫，但可能是棕色的
    - 原因：模型对条件的强调不够强

传统方案：Classifier Guidance
    - 训练一个额外的分类器来判断条件符合度
    - 用分类器的梯度引导生成
    - 问题：需要额外训练，可能放大偏差
```

#### 直观类比：导航

```
场景：从家（噪声）导航到目的地（条件生成）

无条件生成：
    目标：任何地方都行
    路径：随机漫步，可能去公园、商场、公司...

条件生成（无 guidance）：
    目标：去"天安门"
    路径：往天安门方向走，但也会考虑其他有趣的地方
    结果：到天安门附近，但可能绕路

条件生成（有 CFG，guidance_scale=2）：
    目标：去"天安门"
    路径：坚定地朝天安门走，不考虑其他地方
    结果：准确到达天安门，路线清晰

条件生成（有 CFG，guidance_scale=10）：
    目标：去"天安门"
    路径：走直线，不顾一切
    结果：到天安门，但可能走错路（过拟合）
```

### CFG 原理

#### 核心思想

```
关键洞察：
    同一个模型可以同时预测：
    1. 给定条件时的预测 → ε_θ(x_t, t | c)
    2. 不给定条件时的预测 → ε_θ(x_t, t | ∅)

    两者的差异告诉我们：
    "条件如何改变了预测"

CFG 的做法：
    放大这个差异！
    → 更强的条件符合度
    → 更高的生成质量
```

#### 公式表达

```python
# 标准条件生成
ε_cond = ε_θ(x_t, t | c)  # 给定条件 c 的噪声预测

# CFG 增强
ε_cfg = ε_uncond + guidance_scale × (ε_cond - ε_uncond)
       ↑                    ↑             ↑
    无条件预测         强度系数        条件带来的改变

# 简化表示
ε_cfg = ε_θ(x_t | ∅) + w · [ε_θ(x_t | c) - ε_θ(x_t | ∅)]
```

#### 几何解释

```
在高维空间中：

ε_uncond: 任意方向的向量（平均噪声方向）
ε_cond:   朝向条件 c 的向量

ε_cond - ε_uncond:
    ↑
条件 c 带来的"特定方向"

CFG 的作用：
    沿着这个"条件方向"走得更远

    w=1: 正常条件生成
    w>1: 强调条件（更符合文本）
    w<1: 弱化条件（更多样化）
    w=0: 无条件生成
```

### 与 Classifier Guidance 的对比

#### Classifier Guidance (旧方法)

```python
# 需要两个模型

# 1. 扩散模型：预测噪声
ε_θ(x_t, t)

# 2. 分类器：判断条件符合度
p(c|x_t, t)

# 引导公式
ε_guided = ε_θ(x_t, t) - √(1-ᾱ_t) · ∇_x_t log p(c|x_t, t)
           ↑                        ↑
        去噪方向              朝向条件的梯度

问题：
    ✓ 需要额外训练分类器
    ✓ 分类器可能引入偏差
    ✓ 训练复杂度高
    ✓ 计算成本高（两次前向传播）
```

#### Classifier-Free Guidance (新方法)

```python
# 只需一个模型

# 训练时：随机丢弃条件
if random() < dropout_rate:
    c = ∅  # 空条件
loss = ||ε - ε_θ(x_t, t | c)||²

# 推理时：两次预测
ε_uncond = ε_θ(x_t, t | ∅)
ε_cond   = ε_θ(x_t, t | c)

# 引导公式
ε_cfg = ε_uncond + w · (ε_cond - ε_uncond)

优势：
    ✓ 不需要额外分类器
    ✓ 同一个模型完成所有工作
    ✓ 训练简单
    ✓ 计算成本可控（仍是两次前向传播）
```

#### 详细对比表

| 维度 | Classifier Guidance | Classifier-Free Guidance |
|------|---------------------|-------------------------|
| **额外模型** | 需要分类器 | 不需要 |
| **训练方式** | 分别训练扩散+分类器 | 联合训练（随机dropout条件） |
| **训练复杂度** | 高（两个模型） | 低（一个模型） |
| **推理成本** | 2×前向（扩散+分类器） | 2×前向（无条件+条件） |
| **灵活性** | 需要重新训练分类器 | 无需重新训练 |
| **偏差问题** | 可能放大分类器偏差 | 相对较小 |
| **公式复杂度** | 需要梯度计算 | 简单线性组合 |
| **主流程度** | 早期方法 | **当前主流** |

### 数学推导

#### 目标：增强条件对生成的影响

```python
# 我们想要最大化：log p(c|x_t)

# 贝叶斯公式
p(c|x_t) = p(x_t|c) · p(c) / p(x_t)

# 取对数
log p(c|x_t) = log p(x_t|c) - log p(x_t) + log p(c)
               ↑                      ↑
           条件似然              边际似然

# 对 x_t 求梯度
∇_x_t log p(c|x_t) = ∇_x_t log p(x_t|c) - ∇_x_t log p(x_t)
                     ↑                      ↑
                 朝向条件               远离平均
```

#### 在扩散模型中的应用

```python
# 扩散模型的得分函数
∇_x_t log p(x_t) = -ε_θ(x_t, t) / √(1-ᾱ_t)
∇_x_t log p(x_t|c) = -ε_θ(x_t, t|c) / √(1-ᾱ_t)

# 代入上式
∇_x_t log p(c|x_t) = -[ε_θ(x_t, t|c) - ε_θ(x_t, t)] / √(1-ᾱ_t)

# 因此，沿着条件梯度的方向移动：
ε_guided = ε_θ(x_t, t) - √(1-ᾱ_t) · ∇_x_t log p(c|x_t)
        = ε_θ(x_t, t) + [ε_θ(x_t, t|c) - ε_θ(x_t, t)]
        = ε_θ(x_t, t|c)  # 当 w=1

# CFG 引入权重 w
ε_cfg = ε_θ(x_t, t) + w · [ε_θ(x_t, t|c) - ε_θ(x_t, t)]
      = ε_uncond + w · (ε_cond - ε_uncond)
```

#### 为什么这样有效？

```python
# 理解 w 的作用

w = 1:
    ε_cfg = ε_cond
    标准条件生成

w > 1:
    ε_cfg = ε_uncond + w(ε_cond - ε_uncond)
          = w·ε_cond - (w-1)·ε_uncond

    当 w=2:
        ε_cfg = 2·ε_cond - ε_uncond
        → 沿着条件方向走得更远
        → 更强的条件符合度
        → 更高的生成质量

w < 1:
    ε_cfg 更接近 ε_uncond
    → 弱化条件
    → 更多样化

w → 0:
    ε_cfg → ε_uncond
    → 无条件生成
```

#### 训练阶段

```python
import torch
import torch.nn as nn

class CFGTrainer:
    def __init__(self, model, dropout_rate=0.1):
        self.model = model
        self.dropout_rate = dropout_rate

    def train_step(self, x_0, condition):
        """
        x_0: 真实图像 [B, C, H, W]
        condition: 条件（如文本 embedding）[B, D] 或 [B, n, D]
        """
        batch_size = x_0.shape[0]

        # 1. 采样时间步
        t = torch.randint(0, 1000, (batch_size,), device=x_0.device)

        # 2. 采样噪声
        noise = torch.randn_like(x_0)

        # 3. 前向扩散
        x_t = sqrt_alpha_bar(t) * x_0 + sqrt(1 - alpha_bar(t)) * noise

        # 4. 随机丢弃条件（关键！）
        mask = torch.rand(batch_size, device=x_0.device) > self.dropout_rate

        # 丢弃条件的方式取决于条件类型
        if condition.dim() == 2:  # [B, D] 全局条件
            # 对于全局条件，用零向量替换
            condition_dropped = condition.clone()
            condition_dropped[~mask] = 0
        elif condition.dim() == 3:  # [B, n, D] 序列条件
            # 对于序列条件，用零向量替换
            condition_dropped = condition.clone()
            condition_dropped[~mask] = 0

        # 5. 预测噪声
        noise_pred = self.model(x_t, t, condition_dropped)

        # 6. 计算损失
        loss = F.mse_loss(noise_pred, noise)

        return loss

    # 或者更简洁的实现
    def train_step_simple(self, x_0, condition, null_condition=None):
        """
        使用显式的空条件
        """
        t = torch.randint(0, 1000, (x_0.shape[0],), device=x_0.device)
        noise = torch.randn_like(x_0)
        x_t = sqrt_alpha_bar(t) * x_0 + sqrt(1 - alpha_bar(t)) * noise

        # 随机决定是否使用空条件
        if null_condition is None:
            # 创建空条件（零向量）
            null_condition = torch.zeros_like(condition)

        # 随机选择
        use_condition = torch.rand(x_0.shape[0]) > self.dropout_rate
        final_condition = torch.where(
            use_condition.unsqueeze(-1),
            condition,
            null_condition
        )

        noise_pred = self.model(x_t, t, final_condition)
        loss = F.mse_loss(noise_pred, noise)

        return loss
```

```python
class CFGSampler:
    def __init__(self, model, guidance_scale=7.5):

        self.guidance_scale = guidance_scale

        # 3. DDIM 采样循环
        timesteps = torch.linspace(1000, 0, num_steps, device=device)

        for i, t in enumerate(timesteps):

            # 无条件预测

            # 6. DDIM 更新
            x_t = ddim_step(x_t, noise_cfg, t, t_next)

        return x_t
```

#### 实际应用示例（Stable Diffusion）

```python
# Stable Diffusion 风格的实现

class StableDiffusionCFG:
    def __init__(self, vae, unet, clip, guidance_scale=7.5):
        self.vae = vae
        self.unet = unet
        self.clip = clip
        self.guidance_scale = guidance_scale

        # 准备空文本嵌入
        self.null_prompt = ""
        self.null_embedding = self.clip.encode_text(self.null_prompt)

    @torch.no_grad()
    def generate(self, prompt, height=512, width=512, num_inference_steps=50):
        """
        prompt: 文本提示词
        """
        # 1. 编码文本
        text_embedding = self.clip.encode_text(prompt)  # [B, 77, 768]

        # 2. 初始化 latent
        latents = torch.randn(1, 4, height//8, width//8)

        # 3. 采样循环
        for i, t in enumerate(timesteps):
            # 扩展时间步
            t_batch = torch.cat([t] * 2)  # [2]

            # 扩展 latent（无条件 + 条件）
            latent_input = torch.cat([latents] * 2)  # [2, 4, h, w]

            # 扩展文本嵌入（无条件 + 条件）
            text_input = torch.cat([self.null_embedding, text_embedding])  # [2, 77, 768]

            # U-Net 预测
            noise_pred = self.unet(latent_input, t_batch, text_input)  # [2, 4, h, w]

            # 分离无条件预测和条件预测
            noise_pred_uncond, noise_pred_cond = noise_pred.chunk(2)

            # CFG 组合
            noise_pred = noise_pred_uncond + self.guidance_scale * (noise_pred_cond - noise_pred_uncond)

            # DDIM 更新
            latents = ddim_step(latents, noise_pred, t, t_next)

        # 4. 解码
        image = self.vae.decode(latents)

        return image

    def generate_with_guidance_sweep(self, prompt, guidance_scales=[1.0, 3.0, 5.0, 7.5, 10.0]):
        """
        生成不同 guidance scale 的结果，用于对比
        """
        images = []
        for scale in guidance_scales:
            self.guidance_scale = scale
            image = self.generate(prompt)
            images.append(image)

        return images
```

### 条件编码详解

这是 CFG 实现中最关键但常被忽略的部分：**模型如何接收和处理条件**。

#### 核心问题

```python
# 我们调用模型时：
noise_pred = self.model(x_t, t, condition)

# 但 condition 是什么？
# - 文本："a cat on the grass" → 如何变成向量？
# - 类别：5 → 如何嵌入？
# - 空间图：语义图/深度图 → 如何编码？
# - 空 condition：null → 具体是什么？
```

#### 不同类型条件的编码方法

##### 1. 文本条件（最常见）

```python
class TextConditionEncoder:
    """
    使用预训练的文本编码器（如 CLIP）
    """
    def __init__(self, model_name="openai/clip-vit-large-patch14"):
        from transformers import CLIPTokenizer, CLIPTextModel

        self.tokenizer = CLIPTokenizer.from_pretrained(model_name)
        self.text_encoder = CLIPTextModel.from_pretrained(model_name)

        # 关键参数
        self.max_length = 77  # CLIP 的最大 token 数

    def encode(self, text prompts):
        """
        输入：文本字符串列表
        输出：[B, 77, 768] 的 embedding
        """
        # 1. Tokenization
        tokens = self.tokenizer(
            prompts,
            padding="max_length",   # 填充到 77
            max_length=self.max_length,
            truncation=True,
            return_tensors="pt"
        )

        # 2. Text Encoding
        text_embeddings = self.text_encoder(**tokens)

        # 输出形状
        # last_hidden_state: [B, 77, 768]
        # pooler_output: [B, 768]

        return text_embeddings.last_hidden_state

    def encode_null_condition(self):
        """
        空 condition：空字符串
        输出：[1, 77, 768]
        """
        return self.encode([""])

# 使用示例
encoder = TextConditionEncoder()

# 真实条件
text_cond = encoder.encode(["a cat on the grass"])
# 形状：[1, 77, 768]

# 空 condition（用于 CFG）
null_cond = encoder.encode_null_condition()
# 形状：[1, 77, 768]
# 内容：空字符串 "" 的 embedding
```

**关键点**：
- 空 condition = 空字符串 "" 的 embedding（不是零向量！）
- CLIP 的空字符串包含"无特殊意义"的语义
- 确保模型在训练时见过空字符串

##### 2. 类别条件

```python
class ClassConditionEncoder:
    """
    用于类别条件生成（如 ImageNet）
    """
    def __init__(self, num_classes=1000, embedding_dim=512):
        self.embedding = nn.Embedding(num_classes, embedding_dim)

    def encode(self, class_labels):
        """
        输入：类别索引 [B]
        输出：[B, embedding_dim]
        """
        return self.embedding(class_labels)

    def encode_null_condition(self, batch_size):
        """
        空 condition：使用特殊类别（如 num_classes）
        输出：[B, embedding_dim]
        """
        # 方法1：使用预留的 null 类别索引
        null_class_id = self.num_classes  # 假设预留了
        null_labels = torch.full((batch_size,), null_class_id)
        return self.embedding(null_labels)

        # 方法2：零向量
        # return torch.zeros(batch_size, self.embedding_dim)

# 使用示例
encoder = ClassConditionEncoder(num_classes=1000)

# 真实条件
class_cond = encoder.encode(torch.tensor([5, 10, 256]))
# 形状：[3, 512]

# 空 condition
null_cond = encoder.encode_null_condition(batch_size=3)
# 形状：[3, 512]
```

**关键点**：
- 空 condition 可以是预留的特殊类别索引或零向量
- 训练时随机将类别标签替换为 null class

##### 3. 空间条件（语义图、深度图、草图等）

```python
class SpatialConditionEncoder(nn.Module):
    """
    用于空间条件（如 semantic map, depth map）
    """
    def __init__(self, in_channels=3, latent_dim=512):
        super().__init__()
        # 卷积编码器，下采样到 latent 分辨率
        self.encoder = nn.Sequential(
            nn.Conv2d(in_channels, 64, 3, padding=1),
            nn.GroupNorm(8, 64),
            nn.SiLU(),

            nn.Conv2d(64, 128, 3, stride=2, padding=1),  # /2
            nn.GroupNorm(8, 128),
            nn.SiLU(),

            nn.Conv2d(128, 256, 3, stride=2, padding=1),  # /4
            nn.GroupNorm(8, 256),
            nn.SiLU(),

            nn.Conv2d(256, 512, 3, stride=2, padding=1),  # /8
            nn.GroupNorm(8, 512),
            nn.SiLU(),

            # 输出：[B, 512, H/8, W/8]
        )

    def forward(self, spatial_map):
        """
        输入：[B, C, H, W]
        输出：[B, 512, H/8, W/8]
        """
        return self.encoder(spatial_map)

    def encode_null_condition(self, spatial_shape):
        """
        空 condition：零 feature map
        输入：spatial_shape = (B, C, H, W)
        输出：[B, 512, H/8, W/8]
        """
        B, C, H, W = spatial_shape
        return torch.zeros(B, 512, H//8, W//8)

# 使用示例
encoder = SpatialConditionEncoder(in_channels=3)  # RGB semantic map

# 真实条件
semantic_map = load_semantic_map("scene.png")  # [1, 3, 512, 512]
spatial_cond = encoder(semantic_map)
# 形状：[1, 512, 64, 64]

# 空 condition
null_cond = encoder.encode_null_condition(semantic_map.shape)
# 形状：[1, 512, 64, 64]
# 内容：全零 feature map
```

**关键点**：
- 空 condition 通常是零 feature map
- 空间条件需要下采样到与 latent 相同的分辨率

```python
        """
        # 1. 时间步 embedding
        t_emb = self.time_embed(timestep_embedding(t))  # [B, 512]

        # 2. 条件 embedding（关键！）
        if condition is not None:
            # 对于文本：[B, 77, 768] → [B, 512]
            # 对于类别：[B, 512]
            if condition.dim() == 3:  # 序列条件
                cond_emb = condition.mean(dim=1)  # 简单池化
            else:
                cond_emb = condition

            cond_emb = self.cond_embed(cond_emb)  # [B, 512]

            # 3. 组合时间步和条件（关键操作！）
            emb = t_emb + cond_emb  # [B, 512]
        else:
            emb = t_emb  # [B, 512]

        # 4. 传入 U-Net
        # 每个 ResBlock 都会使用 emb
        h = self.down_blocks[0](x_t, emb)
        ...

        return noise_pred

class ResBlock(nn.Module):
    """
    标准的 ResNet Block，带条件注入
    """
    def __init__(self, channels, emb_dim):
        super().__init__()
        self.norm1 = nn.GroupNorm(8, channels)
        self.conv1 = nn.Conv2d(channels, channels, 3, padding=1)

        self.norm2 = nn.GroupNorm(8, channels)
        self.conv2 = nn.Conv2d(channels, channels, 3, padding=1)

        # 条件注入层
        self.cond_layers = nn.Sequential(
            nn.SiLU(),
            nn.Linear(emb_dim, channels * 2)
        )

    def forward(self, x, emb):
        """
        x: [B, C, H, W]
        emb: [B, emb_dim] (时间步 + 条件)
        """
        # 1. 从 emb 生成 scale 和 shift
        scale, shift = self.cond_layers(emb).chunk(2, dim=1)
        # scale, shift: [B, C]

        # 2. 第一个卷积
        h = self.norm1(x)
        h = h * (1 + scale[:, :, None, None]) + shift[:, :, None, None]  # 条件注入！
        h = swish(h)
        h = self.conv1(h)

        # 3. 第二个卷积
        h = self.norm2(h)
        h = h * (1 + scale[:, :, None, None]) + shift[:, :, None, None]  # 条件注入！
        h = swish(h)
        h = self.conv2(h)

        # 4. 残差连接
        return x + h
```

**关键点**：
- **条件 + 时间步 emb 相加**（最简单有效的方法）
- 通过 `scale` 和 `shift` 调制特征图（Feature-wise Linear Modulation, FiLM）
- 适用于全局条件（类别、文本 pooling）

##### 方法 2: Cross-Attention（适用于序列条件）

```python
class SpatialTransformer(nn.Module):
    """
    使用 Cross-Attention 注入条件
    适用于：文本（序列）、空间图
    """
    def __init__(self, channels, context_dim=768, num_heads=8):
        super().__init__()
        self.norm = nn.GroupNorm(8, channels)

        # 投影到 query 维度
        self.proj_in = nn.Conv2d(channels, channels, 1)

        # Cross-attention
        self.attn = CrossAttention(
            query_dim=channels,
            context_dim=context_dim,
            heads=num_heads
        )

        self.proj_out = nn.Conv2d(channels, channels, 1)

    def forward(self, x, context):
        """
        x: [B, C, H, W] - latent features
        context: [B, n, context_dim] - 条件（如文本 embedding）
        """
        # 1. 归一化 + 投影
        h = self.norm(x)
        h = self.proj_in(h)

        # 2. 重排为 tokens
        B, C, H, W = h.shape
        h = h.reshape(B, C, H*W).transpose(1, 2)  # [B, H*W, C]

        # 3. Cross-attention（关键！）
        h = self.attn(h, context)  # [B, H*W, C]
        # Query: latent tokens
        # Key/Value: condition tokens

        # 4. 重排回空间
        h = h.transpose(1, 2).reshape(B, C, H, W)

        # 5. 输出投影
        h = self.proj_out(h)

        # 6. 残差
        return x + h

class CrossAttention(nn.Module):
    def __init__(self, query_dim, context_dim, heads=8):
        super().__init__()
        self.heads = heads
        d_k = query_dim // heads

        self.to_q = nn.Linear(query_dim, query_dim)
        self.to_k = nn.Linear(context_dim, query_dim)
        self.to_v = nn.Linear(context_dim, query_dim)

        self.to_out = nn.Linear(query_dim, query_dim)

    def forward(self, x, context):
        """
        x: [B, n, query_dim] - query
        context: [B, m, context_dim] - key/value
        """
        B, N, D = x.shape

        # Multi-head projections
        Q = self.to_q(x).reshape(B, N, self.heads, -1).transpose(1, 2)
        K = self.to_k(context).reshape(B, -1, self.heads, -1).transpose(1, 2)
        V = self.to_v(context).reshape(B, -1, self.heads, -1).transpose(1, 2)

        # Scaled dot-product attention
        attn = softmax(Q @ K.transpose(-2, -1) / math.sqrt(D), dim=-1)
        out = attn @ V

        # Merge heads
        out = out.transpose(1, 2).reshape(B, N, D)
        return self.to_out(out)

class UNetWithCrossAttention(nn.Module):
    def __init__(self):
        super().__init__()
        self.time_embed = ...
        self.down_blocks = ...

        # 在中间层添加 Cross-attention
        self.transformer_blocks = nn.ModuleList([
            SpatialTransformer(channels=512, context_dim=768)
            for _ in range(3)
        ])

    def forward(self, x_t, t, text_embedding):
        """
        x_t: [B, 4, H, W]
        t: [B]
        text_embedding: [B, 77, 768]
        """
        # 1. 时间步 embedding
        t_emb = self.time_embed(t)

        # 2. 下采样
        h = self.down_blocks[0](x_t, t_emb)
        h = self.down_blocks[1](h, t_emb)

        # 3. 中间层：Cross-attention（注入文本条件）
        for transformer in self.transformer_blocks:
            h = transformer(h, text_embedding)  # 关键！

        # 4. 上采样
        h = self.up_blocks[0](h, t_emb)
        ...

        return noise_pred
```

**关键点**：
- Cross-attention 允许 latent tokens 查询条件 tokens
- Query: latent features
- Key/Value: 条件 embedding
- Stable Diffusion 的标准做法

```python
class UNetWithConcat(nn.Module):
    """
    将空间条件直接拼接到输入
    适用于：语义图、深度图、参考图
    """
    def __init__(self, in_channels=4, cond_channels=3):
        # 输入通道数增加
        super().__init__()
        self.conv_in = nn.Conv2d(
            in_channels + cond_channels,  # 4 + 3 = 7
            64,
            kernel_size=3,
            padding=1
        )

        self.time_embed = ...
        self.down_blocks = ...
        self.up_blocks = ...

    def forward(self, x_t, t, spatial_condition):
        """
        x_t: [B, 4, H, W] - latent
        t: [B] - timestep
        spatial_condition: [B, 3, H, W] - 编码后的空间条件
        """
        # 1. 拼接（关键操作！）
        x = torch.cat([x_t, spatial_condition], dim=1)  # [B, 7, H, W]

        # 2. 卷积
        h = self.conv_in(x)

        # 3. 时间步 embedding
        t_emb = self.time_embed(t)
        h = h + t_emb[:, :, None, None]

        # 4. 其余 U-Net 层
        h = self.down_blocks[0](h)
        ...

        return noise_pred
```

**关键点**：
- 空间条件作为额外通道输入
- 适用于条件与 latent 分辨率相同的情况
- ControlNet 使用类似方法

#### 完整示例：文本条件 + Cross-Attention

```python
class CompleteUNet(nn.Module):
    """
    完整的 U-Net 实现，展示条件编码的完整流程
    """
    def __init__(self):
        super().__init__()

        # 1. 时间步 embedding
        self.time_embed = nn.Sequential(
            nn.Linear(128, 512),
            nn.SiLU(),
            nn.Linear(512, 512)
        )

        # 2. 输入卷积
        self.conv_in = nn.Conv2d(4, 320, 3, padding=1)

        # 3. 下采样块
        self.down_blocks = nn.ModuleList([
            DownBlock(320, 640),
            DownBlock(640, 1280),
            DownBlock(1280, 1280),
        ])

        # 4. 中间层（带 Cross-attention）
        self.mid_block = nn.ModuleList([
            ResBlock(1280, 512),
            SpatialTransformer(1280, 768, 8),  # Cross-attention
            ResBlock(1280, 512),
        ])

        # 5. 上采样块
        self.up_blocks = nn.ModuleList([
            UpBlock(1280, 1280),
            UpBlock(1280, 640),
            UpBlock(640, 320),
        ])

        # 6. 输出卷积
        self.conv_out = nn.Conv2d(320, 4, 3, padding=1)

    def forward(self, x_t, t, text_embedding):
        """
        完整的前向传播

        Args:
            x_t: [B, 4, H, W] - noisy latent
            t: [B] - timestep
            text_embedding: [B, 77, 768] - 文本条件
                            或 None（无条件）

        Returns:
            noise_pred: [B, 4, H, W] - 预测的噪声
        """
        B = x_t.shape[0]

        # 1. 时间步 embedding
        t_emb = self.time_embed(timestep_embedding(t))  # [B, 512]

        # 2. 输入处理
        h = self.conv_in(x_t)

        # 3. 下采样
        # 注意：如果 text_embedding 是 None，无条件
        hs = []
        for down in self.down_blocks:
            h = down(h, t_emb, text_embedding)  # 注入文本条件
            hs.append(h)

        # 4. 中间层
        # 这里是 Cross-attention 的关键位置
        for block in self.mid_block:
            if isinstance(block, SpatialTransformer):
                # Cross-attention 块
                # 如果 text_embedding 是 None，跳过
                if text_embedding is not None:
                    h = block(h, text_embedding)
                else:
                    # 无条件：identity 或使用空 condition
                    pass
            else:
                h = block(h, t_emb)

        # 5. 上采样（带 skip connections）
        for up, skip in zip(self.up_blocks, reversed(hs)):
            h = up(h, skip, t_emb, text_embedding)

        # 6. 输出
        h = self.conv_out(h)

        return h

# 训练时的条件 dropout
def train_step(model, x_0, text_embedding, dropout_rate=0.1):
    """
    训练步骤，演示条件 dropout
    """
    B = x_0.shape[0]

    # 1. 采样时间步和噪声
    t = torch.randint(0, 1000, (B,))
    noise = torch.randn_like(x_0)

    # 2. 前向扩散
    x_t = sqrt_alpha_bar(t) * x_0 + sqrt(1 - alpha_bar(t)) * noise

    # 3. 条件 dropout（关键！）
    # 创建 mask：决定哪些样本保留条件
    mask = torch.rand(B) > dropout_rate  # [B]

    # 准备 batch 的条件
    # 对于被 dropout 的样本，条件设为 None
    batch_conditions = []
    for i in range(B):
        if mask[i]:
            batch_conditions.append(text_embedding[i:i+1])  # 保留
        else:
            batch_conditions.append(None)  # dropout

    # 4. 模型预测
    # 需要处理 None 条件
    noise_pred = []
    for i in range(B):
        cond = batch_conditions[i]
        pred = model(x_t[i:i+1], t[i:i+1], cond)
        noise_pred.append(pred)

    noise_pred = torch.cat(noise_pred, dim=0)

    # 5. 损失
    loss = F.mse_loss(noise_pred, noise)

    return loss
```

### 参数选择

#### Guidance Scale (w) 的影响

```python
# guidance_scale 的典型值范围

w = 1.0:
    - 标准条件生成
    - 多样性最好
    - 条件符合度一般

w = 3.0 - 5.0:
    - 轻微 guidance
    - 平衡质量和多样性
    - 推荐起点

w = 7.5 - 10.0:
    - 强 guidance（Stable Diffusion 默认 7.5）
    - 高质量，高条件符合度
    - 多样性降低

w > 15.0:
    - 过强 guidance
    - 可能过拟合条件
    - 样本饱和、细节过锐化
```

#### 经验法则

| 任务 | 推荐 Guidance Scale | 说明 |
|------|-------------------|------|
| **文本到图像（SD）** | 7.5 - 10.0 | 默认 7.5，平衡质量和多样性 |
| **图像修复** | 3.0 - 5.0 | 不需要太强，保持自然 |
| **风格迁移** | 5.0 - 7.5 | 中等强度，保留内容 |
| **精确控制** | 10.0 - 15.0 | 强调条件 |
| **探索性生成** | 1.0 - 3.0 | 更多样化 |

#### 动态 Guidance Scale

```python
# 在采样过程中动态调整 guidance scale

def dynamic_guidance_schedule(t, T):
    """
    t: 当前时间步
    T: 总时间步
    返回：guidance scale
    """
    # 早期（噪声多）：低 guidance
    # 后期（细节多）：高 guidance

    progress = t / T  # 0.0 到 1.0

    # 线性增加
    w = 1.0 + 6.5 * progress  # 从 1.0 到 7.5

    # 或余弦增加
    w = 1.0 + 6.5 * (1 - cos(progress * π)) / 2

    return w

# 采样循环
for i, t in enumerate(timesteps):
    w = dynamic_guidance_schedule(i, num_steps)

    noise_uncond = model(x_t, t, null_condition)
    noise_cond = model(x_t, t, condition)

    noise_cfg = noise_uncond + w * (noise_cond - noise_uncond)

    x_t = update_step(x_t, noise_cfg, t, t_next)
```

### 优缺点

#### 优点

```python
✓ 无需额外模型
    - 不需要训练分类器
    - 同一个模型完成所有工作

✓ 灵活性高
    - 可以实时调整 guidance scale
    - 同一个模型支持多种强度

✓ 训练简单
    - 只需随机 dropout 条件
    - 不改变模型架构

✓ 效果显著
    - 大幅提升条件符合度
    - 提升生成质量（FID ↓）

✓ 通用性强
    - 适用于各种条件（文本、类别、空间）
    - 适用于各种架构（UNet、DiT）
```

#### 缺点

```python
✗ 计算成本翻倍
    - 需要两次前向传播
    - 采样时间 × 2

✗ 质量与多样性权衡
    - 高 guidance → 高质量，低多样性
    - 需要仔细调参

✗ 过强 guidance 可能过拟合
    - w 过大 → 样本饱和
    - 细节过锐化
    - 失去自然感

✗ 对超参数敏感
    - 不同任务最优 w 不同
    - 需要实验确定
```

#### 核心要点

```python
1. CFG 是什么？
   → 条件预测和无条件预测的加权组合

2. 为什么有效？
   → 放大条件对生成的影响
   → 沿着"条件方向"走得更远

3. 如何实现？
   → 训练：随机 dropout 条件
   → 推理：两次前向传播 + 线性组合

4. 如何调参？
   → 默认 7.5（Stable Diffusion）
   → 根据任务调整（1.0 - 15.0）
   → 平衡质量和多样性
```

#### 常见问题

```python
Q1: guidance_scale 太大会怎样？
A: 样本饱和、过拟合条件、细节过锐化
   解决：降低 w，或使用动态 schedule

Q2: 可以只做一次前向传播吗？
A: 理论上可以（w=1），但失去了 CFG 的优势
   可以用近似 CFG（小模型）

Q3: 训练时 dropout 率多少合适？
A: 通常 10-20%
   太高：模型难以学习条件
   太低：无条件预测弱

Q4: 不同条件可以有不同的 w 吗？
A: 可以！
   例如：w_text=7.5, w_color=3.0

Q5: CFG 适用于所有任务吗？
A: 主要用于条件生成
   无条件生成不需要 CFG
```
